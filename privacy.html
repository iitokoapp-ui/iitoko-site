プライバシーポリシー

堀田 悠真(以下「当方」)は、イイトコ(以下「本アプリ」)における
利用者の個人情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

本アプリは、次の情報を取得します。

情報取得の方法目的
メールアドレス利用者の入力、または Apple ID / Google アカウントでのログイン時に各社から受け取る(※)アカウントの作成・ログイン
表示名利用者の入力、または Apple ID / Google アカウントでのログイン時に各社から受け取る名前(あとから変更可)友だちへの表示
記録した場所・評価・コメント・特徴タグ・訪問日利用者の入力本アプリの機能提供
位置情報記録時および地図表示時に端末から取得近くの場所の表示・記録する場所の特定
プロフィールのアイコン画像(任意)利用者が選んだ写真を、端末で256ピクセル四方に縮小して取得友だちへの表示
記録に付ける写真(任意)利用者が選んだ、または撮影した写真を、端末で縮小して取得友だち・他の利用者への表示(第2項)
プレミアムの契約の状態Apple が発行する取引の情報(商品、有効期限、取引ID)を、当方のサーバーが Apple に確認して保存する友だちの人数制限の解除・広告の非表示

※ Apple ID でログインする際に「メールを非公開」を選んだ場合は、Apple が発行する中継用のアドレスを受け取ります。実際のメールアドレスは当方に届きません。

写真について。

  • 写真は、利用者が選んだ(または撮影した)ものだけが、アップロードされます。
  • アップロードする前に、端末で縮小します。そのとき、撮影位置(GPS)・撮影日時・機種などの情報(EXIF)は取り除きます。
  • 「この日に撮った写真から選ぶ」を使うと、端末の写真の撮影日時と撮影場所を、端末の中だけで参照して、 訪問日と店の近くで撮った写真を候補に出します。これらの情報を、当方に送ることはありません。 写真ライブラリへのアクセスは、利用者が許可したときだけです。
  • カメラは、写真の撮影と、友だちのQRコードの読み取りにだけ使います。

位置情報は、地図を開いたときと記録するときに都度取得します。
バックグラウンドでの常時追跡は行いません。端末の設定で拒否した場合でも、
場所を手動で指定することで本アプリを利用できます。

広告について。本アプリは、Google が提供する広告配信サービス「Google AdMob」を利用して広告を表示します。
表示する広告は、利用者の行動履歴に基づかないもの(非パーソナライズ広告)に限ります。
本アプリは広告識別子(IDFA)の利用許可を求めず、他社のアプリやウェブサイトをまたいだ追跡(トラッキング)も行いません。

ただし、広告の配信・不正の防止・効果の測定のため、Google の広告配信の仕組み(Google Mobile Ads SDK)が、
端末やアプリの利用に関する情報(端末の種類、アプリごとの識別子、IPアドレスから推定されるおおよその地域、
広告の表示・タップの記録、アプリの動作状況など)を収集することがあります。
Google による情報の取り扱いは、Google のポリシー(https://policies.google.com/technologies/partner-sites)をご覧ください。

利用者が本アプリに入力した内容(記録した場所・評価・コメントなど)や、端末から取得した正確な位置情報を、
広告のために Google へ送ることはありません。

プレミアム(有料プラン)を購入した利用者には、広告を表示しません。

2. 情報の共有範囲

本アプリは招待制です。利用者が記録した内容とアイコン画像は、
友だちコード(リンク・QRコード)でつながった友だちにのみ表示されます。

ただし、写真だけは、次のとおり、友だち以外にも表示されることがあります。

写真の公開範囲見える人投稿者名
公開(投稿者名なし)すべての利用者(店のページ・店のカード)表示しない
友だちだけ友だちだけ友だちには表示される
  • 投稿時に、公開範囲を選べます。初期値は「公開(投稿者名なし)」です。 投稿画面に、その旨の案内を表示します。
  • 「公開」の写真は、友だちには、友だちの記録としても表示されるため、友だちには、誰の写真かが分かります。
  • 公開範囲は、投稿後に変更でき、写真はいつでも削除できます。
  • 手動で登録した場所(自宅など)の写真は、公開を選んでも、他の利用者には表示されません。
  • 投稿者名が表示されない写真でも、通報や法令に基づく請求があったときは、当方が投稿者を特定して 必要な対応をとることがあります。
  • 写真は1枚ごとに通報でき、複数の利用者から通報があると、確認が終わるまで、他の利用者には表示されなくなります。 ブロックした相手の写真は、表示されません。

これ以外の情報(記録の内容・アイコン画像など)が、不特定多数に公開されることはありません。
この制限は、アプリ側の作りだけでなく、データベースの行単位アクセス制御
(Row Level Security)によっても強制しています。

ただし、利用者自身が「共有カード」機能で画像を作成し、
SNS等に投稿した場合は、その内容が公開されます。
共有カードに含まれるのは利用者自身の記録のみで、
他の利用者のコメントは含まれません。

3. 外部サービスへの提供

本アプリは、機能の提供のため次の外部サービスを利用します。

サービス提供される情報用途
Supabaseアカウント情報・記録内容・アイコン画像・プレミアムの契約の状態データベース・認証基盤・画像の保管
Cloudflare(Cloudflare R2)記録に付けた写真(縮小後。EXIF は取り除いたもの)写真の保管(非公開の保管領域。期限付きの署名付きURLでのみ配信)
Google Maps Platform地図表示のための位置情報地図の描画
Apple(Sign in with Apple)ログインのための認証情報Apple ID でのログイン(利用者が選んだ場合のみ)。退会時には Apple との連携も解除します
Google(Google ログイン)ログインのための認証情報Google アカウントでのログイン(利用者が選んだ場合のみ)
Apple(App Store・アプリ内課金)プレミアムの購入・更新・解約の情報プレミアムの購入の手続き。お支払い情報(カード番号など)は、Apple が管理し、当方には届きません
Google(Google AdMob)端末・アプリの利用に関する情報(第1項「広告について」)広告の表示
株式会社リクルート(ホットペッパーグルメ Webサービス)店を探すときの検索語と、検索の中心にする位置(現在地、または記録された店の位置)。アカウント情報・記録の内容は送りません飲食店の検索と、店の写真の表示

いずれも本アプリの機能提供と広告の表示に必要な範囲に限られます。

店舗の名称・住所などの基礎データは、Overture Maps Foundation が公開する
オープンデータを当方のデータベースに保持して利用しています。
これに加えて、開店したばかりの店を探すときと、友だちの写真が無い飲食店・カフェに
店の写真を表示するときに、ホットペッパーグルメ Webサービスを利用します。
このとき送るのは上の表の検索語と位置だけで、ホットペッパーから受け取った情報は
当方のサーバーには保存せず、端末に24時間以内だけ保持します。

4. 統計情報の利用について

当方は、将来的に、個人を特定できない形に加工・集計した統計情報を
第三者に提供することがあります。

  • 提供するのは、地域・カテゴリ・時期などで集計した傾向値に限ります
  • 氏名・メールアドレス・個別のコメント・写真を提供することはありません
  • 特定の個人が識別できる粒度では提供しません

この取り扱いに同意いただけない場合は、本アプリの利用を停止し、
退会していただくことで、データは削除されます。

5. 保存期間と削除

  • アカウントが存在する間、記録は保存されます
  • 退会すると、アカウント・記録・写真(公開の写真を含む)・アイコン画像・プレミアムの契約の状態は、すべて削除されます(復元できません)
  • 写真は、利用者が削除したとき、または記録を削除したときにも、保管領域から消します
  • 退会前に、設定画面から自分の記録をCSV / JSON で書き出せます
  • Apple のサブスクリプションは、退会しても自動では解約されません。 端末の「設定」→ Apple ID →「サブスクリプション」から、別に解約してください
  • 写真の通報の記録(通報した利用者・理由)は、運営が内容を判断するために保存します。通報された写真が削除されたとき、または通報した利用者が退会したときに、その通報の記録も削除されます

6. 安全管理

  • 通信はすべて暗号化(HTTPS)しています
  • データベースは行単位のアクセス制御により、権限のない読み取りを遮断します
  • 写真は、非公開の保管領域に置き、期限付きの署名付きURLでのみ配信します
  • プレミアムの有無は、Apple に確認した結果だけを記録し、端末からの申告では変更できません

7. 未成年の利用について

13歳未満の方は本アプリを利用できません。
未成年の方は、保護者の同意を得たうえでご利用ください。

8. 開示・訂正・削除の請求

利用者は、自身の個人情報について開示・訂正・削除を請求できます。
下記の連絡先までご連絡ください。

9. 本ポリシーの変更

本ポリシーを変更する場合は、本アプリ内またはウェブサイト上で告知します。
